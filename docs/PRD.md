# Product Requirements Document (PRD)

## Project Title
Smart Campus Lost and Found Management System

## Overview
A web platform for campus students and staff to report lost items and post found items easily.

## Target Audience
- Campus Students
- University Staff/Faculty

## Features & Scope

### MVP (Mid-term Demo)
- Post lost items (Title, Description, Location, Contact Info).
- Post found items (Title, Description, Location, Contact Info).
- View all reported lost/found items list (CRUD operation).
- Search items by keyword.

### Beta (Final Demo)
- User Authentication (Login/Register).
- User Roles (Admin vs Regular User).
- User profile dashboard to manage own posts.
- Security and deployment.
