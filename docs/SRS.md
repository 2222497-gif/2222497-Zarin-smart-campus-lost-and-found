# Software Requirements Specification (SRS)

## 1. Introduction
This document specifies the software requirements for the Smart Campus Lost and Found Management System.

## 2. Functional Requirements

### MVP Scope
- **FR-1**: Users can submit a lost item report.
- **FR-2**: Users can submit a found item report.
- **FR-3**: Users can view a feed of all lost and found items.
- **FR-4**: Users can delete or update their submitted items.

### Beta Scope
- **FR-5**: Users can register and login.
- **FR-6**: Admins can remove inappropriate posts.
- **FR-7**: System supports Role-Based Access Control (RBAC).

## 3. Non-Functional Requirements
- **Performance**: Response time under 2 seconds for API requests.
- **Usability**: Simple and clean user interface.
- **Security**: Basic input validation and API security.
